Background

I'm Yahye Abdi Sahardiid, a Web Developer, Graphic Designer and AI Agent Developer based in Hargeisa, Somaliland, currently studying ICT at Admas University. I build things end-to-end — from the interface a user taps, to the database behind it, to the automation that runs quietly in the background.

On the development side I work mainly in Python, HTML, CSS, JavaScript, C++ and SQL. I've used this stack to design and build large, real-world management systems — like Hiil Cafe and Barwaqo Fuel Stations — handling everything from ordering and inventory to staff shifts and reporting dashboards. More recently, I've been applying Python to AI agent development, including Jarvis, a personal assistant that automates everyday tasks.

Design is the other half of how I work. I use Photoshop and Canva to create graphics, brand visuals and interfaces that feel as considered as the code behind them — so a project looks professional and functions well at the same time.

Alongside software, I repair mobile phones and laptops — diagnosing hardware and software issues and getting devices working again. That hands-on troubleshooting mindset carries over into how I approach system design: I like understanding how something is built, finding where it breaks, and designing it to hold up in practice.

My goal is simple — build useful, professional and innovative technology that solves real problems for real people and businesses.
